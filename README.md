# Lane & Brew — Day 8 (SITEPRO frontend concept)

A polished static concept for Lane & Brew, 83 Lark Lane, Liverpool L17 8UP. Built for GitHub Pages with separate index.html, style.css, and script.js, original SVG illustrations and image fallbacks. No backend, fake ordering flow or dummy bookings.

- Restaurant: Lane & Brew, 83 Lark Lane, Liverpool L17 8UP.
- Day-to-evening café/restaurant with coffee, breakfast/brunch, Mediterranean-inspired lunch, evening food, cocktails/wine/beer, dog-friendly. ## To run/deploy
Open index.html directly or with VS Code Live Server. Upload folder contents (not parent folder) to the root of the Day-8 GitHub repository; Settings → Pages → Deploy from branch → main / root. Fonts are optional external Google Fonts with system fallbacks. Real social, map and source links naturally require internet.

## Final check before client outreach
Get real hero food + interior photos, official brand font/mark if available, confirmed opening/service times, current menu/prices, permitted booking/contact links. Verify mobile menu/keyboard access and compare against owner-approved facts.
