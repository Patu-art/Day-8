# Day 8 — Lane & Brew · Coffee Kitchen

An unofficial, frontend-only restaurant website concept for Lane & Brew, 83 Lark Lane, Liverpool L17 8UP.

Live preview: https://patu-art.github.io/Day-8/

## What changed

This version replaces the original generic café colour palette, stock imagery, illustrated food and decorative map with the restaurant's actual navy-and-cream brand identity and the six images supplied for this demonstration. The homepage prioritises useful information: food and drink, the venue, the address, directions and Instagram.

The files are plain HTML, CSS and JavaScript. There is no build step, backend, made-up ordering flow or booking system.

## Supplied brand images

All six local assets live in `assets/brand/`:

1. `01-hero-interior.png` — dining area and wall sign; hero and visit.
2. `02-morning.png` — actual coffee photo; morning card.
3. `03-afternoon.png` — sandwiches and plates; afternoon card.
4. `04-evening.png` — drinks and food at a window table; later dining card.
5. `05-venue.png` — exterior with navy signage and outdoor seating.
6. `06-logo.png` — provided logo reference used in header, footer and favicon.

Assets are stored in GitHub under relative paths, not linked to a temporary file host. The import workflow was for one-time transfer and is removed after verification.

## Current facts

The concept uses publicly reported basic venue details and links visitors to https://www.instagram.com/laneandbrew/ for current hours, menu and updates. Service hours require direct confirmation with the business; this site deliberately does not promise a particular evening closing time or accept reservations.

## Before approaching the business

Get the owner's approval for the use of their images, logo and recognizable people's photos and review wording/menu/service details with them. This remains an unofficial client demo, not the official Lane & Brew website. The supplied assets were not independently verified as licensed for public use.
